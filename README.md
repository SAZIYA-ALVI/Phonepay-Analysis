# PhonePe Transaction Analysis Dashboard

An interactive **Power BI dashboard** created to analyze transaction trends, transaction value, customer segments, service performance, and payment status.

> **Note:** This project is created for learning and portfolio purposes using a sample dataset. It is not official PhonePe company data.

## Project Overview

The objective of this project is to transform transaction data into meaningful **business insights** using Power BI.

## Key Analysis

* Total Transactions
* Total Transaction Value
* Unique Users
* Transaction Success Rate
* Monthly Transaction Trends
* Age Group Analysis
* Service-wise Transaction Value
* Top Users by Transaction Value
* Weekday vs Weekend Analysis
* Payment Status Analysis

## Dashboard KPIs

* Total Transactions
* Total Transaction Value
* Unique Users
* Success Rate
* Month-over-Month Growth
